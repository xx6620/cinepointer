# Cinepointer

팀 프로젝트로 진행한 영화 관련 웹 서비스입니다.  
- 목적: 영화 정보 탐색 및 사용자 리뷰/평가 기능 제공

## 주요 기능
- 장르별 영화 목록 및 상세 내용 조회
- 영화별 리뷰 작성/수정/삭제, 댓글 작성/수정/삭제 및 평점 부여
- 기본적인 웹 서비스 구조 구현

## 기술 스택
- Backend: Spring Boot
- DB: MySQL
- Front: HTML/CSS/JS, Thymeleaf

## 담당 역할
- 영화 상세페이지 댓글 작성/수정/삭제 및 평점 부여 기능 구현
- 게시판 글, 댓글 등 전반적인 CRUD기능 구현
